# README



## 1. Description


This directory contains all the headers related to **linked list**, which is a linear data structure, usually used for storing data when exact numbers are not known.



## 2. File Structure


- `full_remover.h` - Contains header implementation for the **full remover**, which removes all the nodes from the linked list.
- `inserter.h` - Contains header implementation for the **inserter**, which inserts a node to the linked list.
- `ll_struct.h` - Contains header implementation for the **linked list structure**.
- `remover.h` - Contains header implementation for the **remover**, which removes a node from the linked list.
