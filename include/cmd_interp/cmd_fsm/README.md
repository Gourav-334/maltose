# README


## 1. Directory Information

This directory contains header files associated to various fragments of **command interpreter's FSM**.


## 2. File Descriptions

- `cmd_fms0.h` - Header file for FSM0 which describes working of FSM from state `0` - `9`.
- `cmd_fms1.h` - Header file for FSM1 which describes working of FSM from state `10` - `19`.
