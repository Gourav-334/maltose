# README


## 1. Directory Information

This directory contains header implementation of the **command interpreter** sub-components.


## 2. File Descriptions

- `cmd_fsm/` - Collection of headers for each part of the **command interpreter FSM**.
- `cmd_fms_main.h` - Header for central handler of FSM, where each part of FSM is assembled.
- `cmd_valid.h` - Header file for the corresponding command validator source code.
- `flag_status.h` - Header file for storage of flag statuses passed by user to the assembler binary.
- `fsm_state_handler.h` - Header file for the corresponding **state handler** for command interpreter.
