# README


## 1. Description

This directory records all the implementation details for the **lexer**.


## 2. Directory Structure

- `token_fsm/` - Header implementation for each part of FSM (set of 10 states).
- `fsm_state_handler.md` - Header implementation for FSM state handler, which handles states of unknown token FSM.
- `cleaner.h` - Header implementation for the code cleanser.
- `token_fsm_main.h` - Header implementation for the main FSM handler.
- `token_recog.h` - Header implementation for the token recognizer, which categorizes token.
- `token_store.md` - Header implementation about the token storehouse, which stores tokens in structures.
