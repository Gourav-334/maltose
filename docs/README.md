# README (`docs/`)


## 1. Description

Whole `docs/` directory is dedicated to documentation. This directory contains clean & clear information about everything, everything that a contributor needs to know.


## 2. File Structure

- `algo/` - Documents algorithms or procedures used for writing nano components, such as functions for a micro component (***Qualine*** stage 5).
- `case_studies/` - Contains case studies conducted before beginning to plan, construct, and deploy the project.
- `components/` - State 5th for **Qualine-SDLC**, dealing with component distribution architecture.
- `lifecycle/` - **Qualine-SDLC** software development lifecycle, followed in making of **DEC**.
- `objectives/` - Contains objectives for each release/ version/ patch (***Qualine*** stage 1).
- `research/` - Contains researched information for knowing standards (***Qualine*** stage 2).
- `user_design/` - Contains various interface designs that were decided to be implemented (***Qualine*** stage 4).
- `tool_list.md` - Lists all tools & dependencies required for modifying the project (***Qualine*** stage 3).
