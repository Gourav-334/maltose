# README


## 1. Description

This directory records all the header files for the **lexer**.


## 2. Directory Structure

- `assets/` - Contains all the assets such as image, media or external documents.
- `code_cleanser.md` - Implementation details about the code cleanser, the core lexer component.
- `fsm_state_handler.md` - Implementation details of FSM state handler, which handles states of unknown token FSM.
- `token_fsm.md` - Implementation details about the whole unknown token FSM component.
- `token_recog.md` - Implementation details about the token recognizer, which categorizes token.
- `token_store.md` - Implementation details about the token storehouse, which stores tokens in structures.
