# FULL LINKED LIST REMOVER



## 1. Description


This file records the implementation of the **full linked list remover**, which removes each node from the target linked list.



## 2. Algorithm


### 2.1 <u>Function</u>:

```c
void remove_all_nodes(Ll_recorder *recorder, char *mode);
```

- `recorder` - Pointer to the recorder that contains target linked list.
- `mode` - Mode for providing feedback.


### 2.2 <u>Steps</u>:

1. Simply remove each node from the head continuously (for efficiency).
