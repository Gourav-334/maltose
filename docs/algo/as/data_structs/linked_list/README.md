# README



## 1. Description


This directory contains all the implementation details related to **linked list**, which is a linear data structure, usually used for storing data when exact numbers are not known.



## 2. File Structure


- `full_remover.md` - Contains implementation details for the **full remover**, which removes all the nodes from the linked list.
- `inserter.md` - Contains implementation details for the **inserter**, which inserts a node to the linked list.
- `ll_struct.md` - Contains implementation details for the **linked list structure**.
- `remover.md` - Contains implementation details for the **remover**, which removes a node from the linked list.
