# COMMON STORAGE



## 1. Description


This file defines the implementation of common storage for lexical units.



## 2. Variables


### 2.1 <u>For Lexer Components</u>:

- `row` - Record of row for reference by units.
- `column` - Record of column for reference by units.
- `point` - The point of ambiguity in code.
- `str_len` - Length of the string passed to the FSM.
- `point_shift` - Length to shift the point cursor back to.
