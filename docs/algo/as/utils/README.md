# README


## 1. Directory Information

This directory contains all the utilities' implementation base that could be used in improving programming & prototyping experience.


## 2. File Descriptions

- `file_sys/` - Contains all the documentation related to file system utilities.
- `string_ops` - Contains all the documentation related to string operation utilities.
- `str_verif/` - Contains all the documentation related to string verifying utilities (against any metric).
