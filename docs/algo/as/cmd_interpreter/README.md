# README


## 1. Directory Information

This directory contains documentation for algorithmic implementation of the **command interpreter** component of **AS**.


## 2. File Descriptions

- `cmd_fms_main.md` - Describes the implementation of central handler of FSM, where each part of FSM is assembled.
- `cmd_valid.md` - Describes the implementation of validating a user passed command to assembler.
- `err_handler.md` - Describes the implementation of error handler for command interpreter.
- `flag_status.md` - Describes the storage flag statuses passed by user to the assembler binary.
