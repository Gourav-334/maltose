# README (`docs/source/`)


## 1. Description

This directory contains all the documentation related to source code, found at `src/` from the root directory.


## 2. File Structure

- `file_finder.c` - Checks if file that is requested for being assembled exists or not.
- `flag_fsm.c` - Finite state machine for interpreting flag names & suggesting right ones as substitute to wrong ones.
- `flag_status.c` - Stores status of the flags which are passed as arguments when assembling.
