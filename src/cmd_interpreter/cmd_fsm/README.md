# README


## 1. Directory Information

This directory contains source codes associated to various fragments of **command interpreter's FSM**.


## 2. File Descriptions

- `cmd_fms0.c` - Source code for FSM0 which describes working of FSM from state `0` - `9`.
- `cmd_fms1.c` - Source code for FSM1 which describes working of FSM from state `10` - `19`.
