# README


## 1. Directory Information

This directory contains source implementation of the **command interpreter** sub-components.


## 2. File Descriptions

- `cmd_fsm/` - Collection of headers for each part of the **command interpreter FSM**.
- `cmd_fms_main.c` - Source code for central handler of FSM, where each part of FSM is assembled.
- `cmd_valid.c` - Source code for the command validator, which validates if a command is right or not.
- `err_handler.c` - Source code for the error handler for command interpreter.
- `flag_status.c` - Source code for storage of flag statuses passed by user to the assembler binary.
