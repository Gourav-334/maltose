# README


## 1. Directory Information

This directory contains all the source codes for x86-based binary generator.


## 2. Directory Structure

- `instr_writer/` - Contains all set of procedures to follow for detected instruction.
- `bin_sec_store.c` - Stores all the binary sections using respective pointers.
- `specs_assign.c` - Assigns binary specifications as per environment in use.
- `specs_store.c` - Stores binary specifications after being assigned.
