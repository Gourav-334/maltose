# README



## 1. Description


This directory contains all the source code related to **linked list**, which is a linear data structure, usually used for storing data when exact numbers are not known.



## 2. File Structure

- `full_remover.c` - Contains header implementation for the **full remover**, which removes all the nodes from the linked list.
- `inserter.c` - Contains source code for the **inserter**, which inserts a node to the linked list.
- `remover.c` - Contains header implementation for the **remover**, which removes a node from the linked list.
