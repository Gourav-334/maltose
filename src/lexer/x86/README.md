# README


## 1. Description

This directory records all the source code for the **lexer**.


## 2. Directory Structure

- `token_fsm/` - Contains source code for each part of FSM (set of 10 states).
- `cleaner.c` - Contains source code for the code cleanser.
- `token_fsm_main.c` - Contains source code for the main FSM handler.
- `token_recog.c` - Contains source code for the token recognizer, which categorizes token.
